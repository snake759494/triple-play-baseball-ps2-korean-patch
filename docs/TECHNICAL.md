# 기술 설명

## 디스크

- 원본은 CD 이미지(BIN/CUE, MODE2/2352)이며 ISO9660 파일 시스템만 있습니다(UDF 없음).
- 수정한 파일은 Form1 섹터로 다시 쓰고 EDC/ECC를 계산합니다. 원래 자리를 넘는 파일은 이미지 끝에 붙이고 디렉터리 레코드를 고칩니다(`tools/cdbuild.py`).
- 실행파일은 `SLUS_201.68`이며 심볼이 남아 있습니다. 가상 주소 = 파일 오프셋 + `0xff000`.

## 텍스트

| 위치 | 내용 | 방식 |
| --- | --- | --- |
| `ZFETEXT.ENG` (1,372개) | 프런트엔드 문자열 | 표 재작성(`tools/textdb.py`) |
| `ZIGTEXT.ENG` (415개) | 경기 중 문자열 | 같은 방식 |
| `FELAYOUT.BIG` | `.fel` 레이아웃 라벨 | BIGF 아카이브 안 RefPack(`0x10FB`) 압축 해제 → `TX:`/`TB:` 줄의 9번 필드(텍스트) 교체, 그림자 줄은 본문 줄과 폰트를 맞춤 → 재압축 |
| 실행파일 | 포지션·구종, 선수 만들기, 메모리 카드 안내, 조작 도움말 등 693개 | 제자리에 넣고, 넘치면 로그 전용 문자열 자리로 옮겨 데이터 포인터와 `lui/addiu`의 하위 16비트를 고침(`tools/elfstrings.py`, `elfrefs.py`, `elfpool.py`) |
| 실행파일 `0x2bf674` | 구장 정보 31곳(128바이트 단위) | `tools/stadium.py` |
| `DATA/ZPLAYERS.ATT`, `ZSTATIC.BIG` 안 `zplayers.att` | 선수 이름·성(각 16바이트) | 이름·성 칸 쌍을 찾아 15바이트 이내로 교체(`tools/players.py`) |
| EAGL `.O` 텍스처 | 메뉴 라벨 그림 약 140장 | ELF 재배치 파일 안 8bpp CSM1 팔레트 텍스처를 원본 채움·외곽선 색으로 다시 그림(`tools/eagl.py`, `imgko.py`) |

- **포지션 약어 원본 표(`0x3e2e88`~)는 바꾸면 안 됩니다.** 게임이 내부 키로도 써서, 한글로 바꾸면 경기 HUD 글자가 모두 사라집니다(폰트 포인터 NULL). 표시용 표 `PositionAbv`(`0x3486ec`)의 포인터만 새 한글 사본을 가리키게 했습니다.
- 기록 약어 `1B/2B/3B`는 로스터 포지션 칸과 문자열을 공유해 "1루·2루·3루"로 옮겼습니다. 경기 중 `R`은 다른 칸과 공유해 원문을 유지합니다.

## 한글 출력

- EA FONT 라이브러리의 SFN(`FNTS`) 글리프 표는 12바이트 `[코드 u16, 폭, 높이, u, v, 전진폭, x오프셋, y오프셋, 0]`이며 16비트 코드를 이진 탐색합니다. 그래서 글리프를 정렬해 추가하기만 하면 됩니다(`tools/sfn.py`, `kfont.py`).
- 인코딩: 한글 n번째 글자 = 선행 `0x81 + n/128`, 후행 `0x80 + n%128`.
- 실행파일 패치(`tools/elfpatch.py`)
  - `FONT_buildmesh`의 1바이트 읽기(`0x2d09b8`)를 미사용 함수 `FONT_drawtextw`(`0x2d1100`) 자리로 넘겨, 0x80 이상이면 다음 바이트와 합칩니다.
  - `FONT_texturesize` 텍스처 한 변 상한 256 → 512 (`0x2b27c8`, `0x2b27d8`).
  - `EAGLFontInit` 폰트 캐시 32 × 32KB → 16 × 128KB (`0x25f3a0`, `0x25f3a8`). 32 × 128KB는 메모리 부족으로 멈춥니다.
  - `FONT_allocmesha` 정점 버퍼를 문자열 바이트 수 × 256 → × 128 (`0x2d1368`). 한글은 2바이트가 글리프 1개라 그대로 두면 경기 HUD 폰트 힙이 바닥납니다.

## 16:9 와이드 패치

- 3D 투영 행렬은 `EAGL::ViewPort::SetPerspective`(`0x2bdd28`)에서 만듭니다. 시야각 반각의 탄젠트를 t라 하면 `m00 = 1/t`, `m11 = -aspect/t`입니다.
- 패치는 명령 3개를 바꿉니다.
  - `0x2bde10` `lui at,0x3f80` → `lui at,0x3f40`: 분자 1.0을 0.75로 바꿔 `m00 = 0.75/t`(가로 시야 4/3배).
  - `0x2bde34` `lwc1 f20,0x30(sp)` → `div.s f0,f0,f20`: `m11 = -aspect/t`를 원래 값 그대로 계산.
  - `0x2bde38` `mul.s f0,f0,f1` → `lwc1 f20,0x30(sp)`: 위에서 밀린 레지스터 복원.
- 이 함수는 한글판과 원본에서 주소와 내용이 같아 두 pnach의 패치 내용이 같고, 파일 이름의 CRC만 다릅니다(한글판 `146E1999`, 원본 `69952C2E`).
- 2D 그림(HUD, 메뉴, 로고)은 4:3 기준 좌표 그대로라 가로로 늘어납니다.
